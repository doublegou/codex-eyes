# Application icon

`AppIcon.png` is the image supplied by the project owner for the application icon.
It contains the OpenAI Blossom mark inside an eye illustration. The image is not
licensed under the source code's MIT license; no rights to OpenAI's marks are
granted by this repository.

The current image is used for the local preview build. Before public distribution,
replace its central mark with original artwork or obtain applicable permission.
OpenAI's published guidelines prohibit incorporating its logo into another brand.

Guidelines: https://openai.com/brand/
