# 支持范围与验证

## 支持

- macOS 14+，Apple Silicon 和 Intel 构建；首先在 Apple Silicon 验证。
- ChatGPT 登录型 Codex 账号，复用 codex-auth 0.3.1 存储。
- 本机 `sessions/`、`archived_sessions/` 中的普通 JSONL 日志。
- Codex 官方 Hooks：需用户信任定义，客户端版本必须提供对应事件。
- 官方独立 Codex App 和集成 ChatGPT App 的常见 CLI 安装位置。

## 已知边界

- 不提供运行中客户端的账号热切换，不自动退出或重启后台进程。退出检测采取保守策略：发现任何相关 Codex 客户端或后台进程都拒绝更改登录，即使其可能使用其他 CODEX_HOME。
- 当前配置不是运行账号证明。没有核验运行身份时不显示“已生效”。
- 账号添加自动同步本机 Codex 登录文件；用户在现有客户端完成登录，工具不再启动登录命令。只在普通 ChatGPT 网页登录不会必然更新本机 Codex 配置；不读取浏览器 Cookie。繁忙时会延后同步，文件监听之外每15秒重试检查。
- 不接云端任务。不会自动跟随桌面端当前选中的聊天；默认显示最近活跃本机会话，可手动固定。
- 本机 token 统计基于保留日志，不是服务端账单或账号额度。日志删失、缺少用量事件、未记录压缩用量、未知继承格式会导致统计不完整。
- `.jsonl.zst` 压缩日志暂不读取，并在面板提示。不是完整的 ccusage 替代品。
- Hooks 不直接提供所有错误与等待用户输入状态；没有明确事件时不推断“等你回答”。历史运行状态可能因崩溃或丢失停止事件而过期，界面标注本机记录来源。
- Hooks 定义可合并，但外部程序同时编辑 hooks.json 仍有竞争风险；操作前会保留备份。信任状态不能从配置存在推断。
- 配置过 Hooks 的 App 如被移动，需要重新连接。卸载前先断开连接。
- 使用后台额度接口的兼容性随服务更新变化；保留未知状态与缓存，不绕过登录失败，不做生成请求探测。
- 支持显式系统代理与代理环境变量，暂不执行 PAC 自动代理脚本。
- 不包含自动更新功能；通用设置底部显示当前版本。
- 应用语言支持简体中文和英文；跟随系统使用首选语言，其他语言回退到英文。外观覆盖仅作用于 Codex Eyes，菜单栏模板图标仍遵循系统菜单栏着色。
- 全局快捷键需要 ⌘ 或 ⌃，避免接管退出、隐藏、复制粘贴等常用组合；注册失败时保留原设置。其他软件后续抢占快捷键不在本 App 控制范围内。

## 验证方式

自动测试全部使用临时目录、合成账号和日志，不切换真实登录，不安装用户 Hooks。覆盖额度时效与错误、查看隔离、后台检测、重复归档、增量半行、子会话继承、压缩、Hooks 合并／断开、进程输出与超时等。

本机渲染检查覆盖浅色和深色。通用包通过交叉编译及 Mach-O 架构检查；Intel 实机、macOS 14 实机、真实登录切换、系统通知横幅、开机启动和 Developer ID 公证需要对应环境的发布验收，不能仅以构建成功代替。
