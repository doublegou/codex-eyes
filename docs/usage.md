# 使用指南

## 菜单栏与看板

菜单栏圆环显示当前登录配置对应账号的剩余比例，优先取 5 小时窗口，没有时取每周窗口；缺少有效数据时显示横线。
点击圆环，或按默认快捷键 **⌘⇧E** 展开看板。快捷键可在“通用”设置中修改。

账号卡片用于切换查看。查看其他账号不会改变登录配置或菜单栏显示的账号，再次展开面板时回到当前登录配置对应的账号。
额度窗口以服务端实际返回为准；仅提供每周额度时，只显示每周圆环。
查询失败时保留缓存；超过十分钟未成功确认，不显示绿色可用状态。

“通用”设置支持语言、外观、隐私模式、减少动画、开机启动和快捷键。
语言支持跟随系统、简体中文与 English，外观支持跟随系统、浅色与深色。
快捷键需包含 ⌘ 或 ⌃；无效或冲突的组合不会覆盖原设置，旁边的恢复按钮可重置为 ⌘⇧E。

## 账号管理

在本机 Codex 客户端完成登录后，应用监听实际 `CODEX_HOME/auth.json` 的变化，并将账号同步到列表。
文件监听之外每 15 秒检查一次；繁忙时延后同步。普通 ChatGPT 网页登录不一定会更新本机 Codex 登录文件，应用不读取浏览器 Cookie。

“账号”设置提供备注、排序和移除操作。查看额度始终只改变看板展示。
真实登录切换默认关闭；启用后可通过面板左上角，或设置中的“切换登录”选择其他账号。

更改登录前必须完全退出相关 ChatGPT / Codex 客户端和后台进程。关闭窗口不等于退出。
应用会检查进程，仍在运行或无法确认时阻止切换，不自动退出客户端或重启任务。
确认框中的“不再提醒”仅省略后续确认，不跳过退出检查。
配置切换后在下次启动客户端时生效；配置文件中的账号不代表已经核验运行中客户端的身份。

## 用量统计

| 指标 | 范围 |
| --- | --- |
| 今日用量 | 按 Mac 当前时区，从零点开始记录的本机 Token 增量 |
| 会话用量 | 所选本机会话已记录的累积 Token |
| 上下文 | 会话中最近一次记录的上下文占用，并非实时客户端状态 |
| 累积用量 | 所列账号官方 `lifetimeTokens` 之和，包含其他设备上的使用 |
| 账号每日活动 | 服务端返回的每日记录，可能延迟，不按 Mac 时区重新分桶 |

输入包含缓存输入，输出包含推理输出，均不额外重复相加。缺少明细时不推算比例。
官方账号数据不全时显示已知小计与 ≥，不计算账号占比；查询失败保留缓存并标记。
本机日志无法可靠确认中途切换账号后的实际归属，因此不按账号拆分历史日志。

主面板“用量活动”支持 7 天、30 天和全部：7 天使用柱状图，30 天和全部使用热力图。
紧凑面板的长历史会按周、月或年合并，悬停显示对应日期范围与用量。
“用量明细”窗口提供本机总览、会话排行、会话明细与各账号活动；账号和本机总览的完整热力图按日展示。
账号柱状图显示最近 30 条服务端记录，热力图覆盖全部已返回记录。缺失记录不当作真实的零用量。

本机统计受日志保留范围和格式影响；已删除、缺失用量事件或暂不支持的压缩日志无法计入。
完整边界见[支持范围](compatibility.md)。

## 任务提醒

1. 将应用安装到最终位置后，打开“设置 → 通知”。
2. 在任务事件一栏点击“连接”。
3. 在 Codex 的 `/hooks` 中检查并信任 Codex Eyes 的定义，再运行一轮任务。
4. 允许系统通知，并启用需要的提醒分类。

连接会合并并备份已有 Hooks，断开时只移除 Codex Eyes 自己的配置。
配置存在不代表已经信任，历史事件也不能证明新路径已完成验证。
移动应用或定义变化后需要重新连接并审查；卸载前先断开连接。

任务提醒基于收到的事件；本轮结束不表示整个任务完成。
通知默认关闭，支持额度偏低、其他账号恢复可用，以及等待授权、失败和本轮结束提醒。
额度和 Token 统计不依赖任务连接。

## 数据与隐私

- 账号凭据由内置 codex-auth 管理，使用实际 `CODEX_HOME`，默认 `~/.codex`。
- 额度查询直接访问 OpenAI 服务，不发送生成请求探测可用性，不接入第三方业务服务器。
- 官方账号统计通过独立 Codex App Server 的 `account/usage/read` 查询。查询使用受限权限的临时凭据副本，清空刷新令牌，完成后清理，不更改原登录配置。
- 偏好保存在 UserDefaults；统计缓存、索引和最小事件记录保存在 `~/Library/Application Support/CodexEyes/`。
- 日志索引保存文件位置、会话标识、项目末级目录名、模型、用量和时间，不缓存聊天正文。缓存目录权限为 0700、文件为 0600。
- 隐私模式隐藏邮箱和会话名称；备注由用户自行填写，截图与反馈前仍应检查敏感信息。
- 支持显式 HTTP / HTTPS / SOCKS 系统代理与代理环境变量，不修改系统网络设置。

应用不提供自动更新。新版本可从 [Releases](https://github.com/doublegou/codex-eyes/releases) 下载，当前版本号位于“通用”设置底部。
